# Pro3_W1_Ex6 (じゃんけんゲーム)

このリポジトリは、プログラミング3 (2025) の 1 回目の発展課題のソースコードを含めたものです。

![](/screenshot.png)

## Target

- 自分の出し手の偏りを知り矯正する
- じゃんけんの勝率は理論値の 33.3 % に近づくのか検証する

## Usage

1. 起動します。
2. 出し手を選択します。
3. 勝ちます。あるいは負けます。あるいは引き分けます。

## Features

講義資料に課されている発展課題 6 との仕様の違いは以下のとおりです。

### User Interface (UI)

- 相手の出し手と自分の出し手がわかりやすくなりました
- 勝ち負けがわかりやすくなりました

### Function

- 起動時から、相手の出した手と自分の出した手の回数を計測し表示するようになりました
